# ROXAMI Website

A responsive, static website for the ROXAMI open-source software studio.

## Files
- `index.html` — website content
- `styles.css` — layout, colours and responsive styling
- `script.js` — mobile navigation and current year
- `favicon.svg` — browser icon

## Publish with GitHub Pages

1. In the `roxami-tech` GitHub organization, create a **public** repository named exactly `roxami-tech.github.io`.
2. Upload all four website files to the repository root (not inside another folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site.

Your website address will be:

https://roxami-tech.github.io/

## Before publishing
- Confirm the Nuvote repository has been transferred to `https://github.com/roxami-tech/nuvote`. If you use a different repository name, update the Nuvote link in `index.html`.
- Replace any planned app details as your roadmap changes.
- Add real social links and a contact email when those accounts are ready.

## Local preview
Open `index.html` in a browser. The website uses Google Fonts when an internet connection is available and falls back to system fonts otherwise.
